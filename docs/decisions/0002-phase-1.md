# Decision 0002: Phase 1 app foundation

> Historical record: this phase implemented the original Expo prototype. Decision [0004](0004-pwa-pivot.md) supersedes its platform and APK release choices; the current production target is the Next.js PWA on Vercel.

**Status:** Implemented locally; native device validation is pending.

## Decisions

- Keep the app in `apps/mobile` as an Expo SDK 57, React Native, TypeScript application with Expo Router.
- Use a custom `react-native-svg` line chart so the planned trajectory, measured trend, weigh-in points, and missing measurements have explicit visual semantics.
- Use internal EAS distribution with APK output for private Android installation. The development profile includes `expo-dev-client`; preview and production profiles are internal APKs.
- Keep sample data clearly labeled until the data, identity, and sync phases are implemented.
- Use the current Android package ID `com.siddharthg2309.healthcare` as a working value, not a confirmed release identity.

## Verification

- The four tabs and Home-to-Progress navigation were exercised in a 390 x 844 browser preview.
- TypeScript, lint, Expo dependency compatibility, and public Expo config checks passed.
- The graph rendered with its planned and measured lines, point labels, and explicit gaps.

## Remaining checks

- Install and navigate the development APK on the owner's Android phone, including system font scaling and Android Back behavior.
- Confirm the application display name and package ID before the first signed APK.
- EAS account setup and signing are required to produce a privately installable APK; no credentials or signing keys belong in this repository.
- Expo Doctor reports a macOS host Xcode version check failure (the configured app targets Android and web only); its Android-relevant dependency/configuration checks pass. npm audit reports 29 upstream Expo/React Native toolchain advisories (11 moderate and 18 high), and the safe npm remediation leaves them unresolved. Recheck upstream patches before a shared release.
